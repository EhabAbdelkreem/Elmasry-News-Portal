دليل الرفع الكامل والشامل لمنصة بوابة المصري الإخباري على MonsterASP.NET
(Angular 18 + ASP.NET Core 8 Web API + MS SQL Server)
================================================================================

أهلاً بك يا باشمهندس إيهاب!
تم تجهيز وضبط المشروع بالكامل ليكون جاهزاً للرفع على MonsterASP.NET وربطه بدومينك الخاص.

اتبع هذه الخطوات المرتبة بدقة:

--------------------------------------------------------------------------------
المرحلة الأولى: إنشاء قاعدة بيانات SQL Server على MonsterASP.NET
--------------------------------------------------------------------------------
1. ادخل إلى لوحة تحكم MonsterASP.NET:
   https://www.monsterasp.net/
2. من القائمة الجانبية اضغط على (Databases) -> ثم (Create Database).
3. اختر نوع قاعدة البيانات: MS SQL Server.
4. اكتب اسم قاعدة البيانات، مثلاً: AlmasryNewsDb
5. أنشئ اسم مستخدم (Username) وكلمة مرور قوية (Password) واحفظهما معك.
6. بعد الإنشاء، اضغط على زر (Manage) أو افتح (Web Web-Admin / myLittleAdmin) المدمج في لوحة التحكم، أو اتصل بها من جهازك عبر SQL Server Management Studio (SSMS) باستخدام Host السيرفر المعطى لك.
7. افتح ملف `Database_Setup.sql` الموجود في مجلد المشروع، وانسخ كل محتواه والصقه في شاشة تنفيذ الـ SQL ثم اضغط (Execute).
   * بهذا ستُنشأ جميع الجداول مع المقالات والأقسام وحسابك Superadmin:
     (ehababdelkreem012@yahoo.com / 01282407472ehab).

--------------------------------------------------------------------------------
المرحلة الثانية: تجهيز ملف الاتصال (Connection String)
--------------------------------------------------------------------------------
1. في مشروعك داخل المجلد `backend/appsettings.json`:
   قم بتحديث سطر `DefaultConnection` بالبيانات الحقيقية التي أخذتها من MonsterASP:
   
   "ConnectionStrings": {
     "DefaultConnection": "Server=tcp:YOUR_SERVER_HOST,1433;Database=AlmasryNewsDb;User Id=YOUR_DB_USER;Password=YOUR_DB_PASSWORD;TrustServerCertificate=True;MultipleActiveResultSets=true;"
   }

--------------------------------------------------------------------------------
المرحلة الثالثة: استخراج ملفات النشر (Publish) بنقرة واحدة
--------------------------------------------------------------------------------
لقد أنشأت لك ملفاً تنفيذياً جاهزاً في جذر المشروع:
1. اضغط نقرتين على ملف:
   👉 `نشر_المشروع_للاستضافة.bat`
2. سيقوم تلقائياً بتجميع المشروع وعمل `dotnet publish` وتجهيز مجلد اسمه:
   📁 `publish_monsterasp`
   (ويحتوي على ملف `web.config` المضبوط لـ IIS وجميع ملفات الـ DLL).

3. ادخل داخل مجلد `publish_monsterasp`، وحدد جميع الملفات التي بداخله واضغط:
   (Right Click) -> Send to -> Compressed (zipped) folder
   وسمه مثلاً: `site_deploy.zip`.

--------------------------------------------------------------------------------
المرحلة الرابعة: الرفع على MonsterASP.NET
--------------------------------------------------------------------------------
1. في لوحة تحكم MonsterASP.NET، توجه إلى (Websites) واختر موقعك أو اضغط (File Manager).
2. افتح المجلد الرئيسي: `site` أو `wwwroot`.
3. اضغط على خيار (Upload) وارفع ملف `site_deploy.zip`.
4. اضغط كليك يمين على الملف المرفوع في لوحة التحكم واختر (Extract / Unzip) لاستخراج المحتويات مباشرة داخل المجلد.
5. تأكد أن ملف `web.config` وملف `AlmasryNews.Api.dll` موجودان مباشرة داخل مجلد الـ root للموقع.

--------------------------------------------------------------------------------
المرحلة الخامسة: ربط الدومين الخاص بك (Custom Domain)
--------------------------------------------------------------------------------
1. في لوحة MonsterASP، اذهب إلى (Websites) -> (Domains).
2. اضغط على (Add Domain) واكتب اسم الدومين الخاص بك (مثلاً: almasry-news.com أو www.almasry-news.com).
3. سيعطيك MonsterASP أرقام الـ DNS أو الـ CNAME / A-Record.
4. ادخل إلى لوحة تحكم مزود الدومين الخاص بك (GoDaddy, Namecheap, Cloudflare, etc):
   - قم بإضافة A Record يشير إلى IP السيرفر الخاص بـ MonsterASP.
   - أو قم بإضافة CNAME لـ www يشير إلى عنوان موقعك في MonsterASP.
5. تفعيل شهادة الأمان (SSL):
   من لوحة MonsterASP اذهب إلى (SSL Certificates) واضغط على (Enable Free Let's Encrypt SSL) ليصبح موقعك يعمل بـ https:// بأمان مجاناً.

--------------------------------------------------------------------------------
المرحلة السادسة: التحقق والتأكد من العمل
--------------------------------------------------------------------------------
- افتح رابط موقعك أو دومينك:
  https://yourdomain.com/
  ستفتح لك واجهة Swagger الكاملة ومسارات الـ API.
- يمكنك فحص الرابط:
  https://yourdomain.com/api/status
  ليؤكد لك السيرفر: status: running.
- وتفقد مسار المقالات:
  https://yourdomain.com/api/articles

مبروك! موقعك الآن شغال Full-Stack أونلاين على السيرفر والدومين بنجاح.
